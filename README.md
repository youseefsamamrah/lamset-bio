# لمسة بيو

عارض تفاعلي ثلاثي الأبعاد للجزيئات الحيوية، بواجهة بيضاء زجاجية. اختَر النموذج، حرّكه، وحدّد الذرات أو الأجزاء مباشرةً.

## الموقع

[افتح لمسة بيو](https://youseefsamamrah.github.io/lamset-bio/)

## المزايا

- 19 نموذجًا من السكريات والدهون والبروتينات.
- تدوير وتقريب، وتحديد الأجزاء أو جميع ذرات عنصر.
- أسماء الذرات على الجزيئات واسم النموذج على الإنزيم.
- مشاهد نزع الماء والتحلّل بالماء، مع الماء والمكوّنات.
- وضع عرض، بحث عربي وإنجليزي، وحفظ صورة PNG.
- يعمل على الهاتف والكمبيوتر ويحترم إعداد تقليل الحركة.

المحتوى منتقى من الدفتر. بعض النماذج رسومات عامة مبسّطة بأطوال سلاسل تمثيلية، ومقاطع عديدات التسكر ليست الجزيء الكامل. مشاهد التفاعل تعرض البنية قبل الارتباط وبعده.

## التشغيل

يتطلب Node.js 22.13 أو أحدث.

~~~bash
npm ci
npm run dev
~~~

~~~bash
npm test
npm run typecheck
~~~

## النشر

سير العمل في .github/workflows/pages.yml ينشر الموقع تلقائيًا على GitHub Pages عند الدفع إلى main. مصدر Pages في إعدادات المستودع هو GitHub Actions.

لبناء نسخة تحت مسار مخصص، عيّن PAGES_BASE_PATH مثل /lamset-bio/ ثم نفّذ npm run build:pages. الناتج في dist-pages.

## الملفات

واجهة العرض في app/LiquidLab.tsx، ومحرك Mol* في app/MolstarStage.tsx. النماذج محفوظة محليًا في public/models، وربطها بمحتوى الدفتر في app/moleculeCatalog.ts. اختبارات tests تتحقق من سلامة النماذج وحفظ الذرات ومجال الكاميرا.

## مكتبات العرض

يستخدم العارض Mol* وReact، وخط IBM Plex Sans Arabic وأيقونات Phosphor. إشعارات تراخيص هذه المكتبات محفوظة في public/molstar/LICENSE وpublic/licenses. مصادر النماذج في public/models/README.md.
